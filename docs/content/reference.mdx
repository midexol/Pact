# API Reference

PACT exposes REST endpoints for managing commitments, querying memory, and running demo scenarios.

## Endpoints Summary

- **Propose Commitment**: `POST /api/commitments`
- **Accept Commitment**: `POST /api/commitments/id/accept`
- **Deliver Commitment**: `POST /api/commitments/id/deliver`
- **Evaluate Commitment**: `POST /api/commitments/id/evaluate`
- **Settle Commitment**: `POST /api/commitments/id/settle`
- **Search Memory**: `GET /api/memory/search`
- **Agent History**: `GET /api/agents/id/history`
- **Trigger Demo**: `POST /api/demo`
